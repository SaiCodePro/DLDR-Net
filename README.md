# DLDR-Net
Intelligent Dynamic Relaxation Detection for RIS-Assisted Massive MIMO Systems
https://ieeexplore.ieee.org/document/11810779
Abstract:
In this paper, a deep learning (DL)-based approach is proposed to enhance symbol detection in reconfigurable intelligent surface (RIS)-assisted massive multiple-input multiple-output (MIMO) systems. It has been shown that the integration of RIS with massive MIMO can significantly improve detection performance. However, such integration introduces considerable detection complexity, particularly when the number of antennas and/or RIS reflection elements becomes large. To address these challenges, a low-complexity detection method, namely modified dynamic relaxation (MDR), is developed, in which momentum-based optimization techniques with high momentum are incorporated to enhance symbol detection. Furthermore, to overcome the performance limitations of the fixed MDR parameters, a deep learning-based dynamic relaxation network (DLDR-Net) is introduced, where the network parameters are determined through DL training. In particular, two trainable vectors, rather than matrices, are assigned between each layer of DLDR-Net to enable layer-by-layer refinement of the detection process. Through simulation and complexity analysis, the results demonstrate that the proposed DLDR-Net, aided by high-momentum techniques, achieves comparable or improved performance relative to existing DL-based detectors, while maintaining a manageable computational load.
